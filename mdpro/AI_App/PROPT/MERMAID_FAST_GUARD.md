# AI JENA Mermaid 직접 생성 규칙

2026-09-01: 검증 방식은 폐기했다. 과거 링크 호환을 위해 파일명만 유지한다.

- 노드 ID는 N1, N2처럼 영문과 숫자로 작성한다.
- 라벨을 큰따옴표로 감싸고 내부 따옴표는 #quot; 등으로 표현한다.
- 노드와 연결은 각각 별도 줄에 선언한다.
- subgraph와 mermaid 코드 펜스를 완전히 닫는다.
- 요청하지 않은 HTML, 아이콘, 클릭 동작은 생략한다.
- 호스트 앱이 지원하는 문법과 읽기 쉬운 색상을 사용한다.

AI가 직접 결과를 생성한다. 사전 검증, 추가 AI 자동 수정, 검증 실패에 따른 삽입 차단은 실행하지 않는다. 미리보기 렌더러와 편집기의 Undo/Redo는 유지한다. 문법이나 의미의 정확성을 보장하지는 않는다.
