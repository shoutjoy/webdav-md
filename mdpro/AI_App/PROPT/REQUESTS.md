# AI Jena 요청 정리

## 이전 요청: 응답 구조와 컨텍스트 최적화

- 즉시응답에서도 사용자용 `응답 설명`과 `최종 답변`을 분리한다.
- 응답 설명은 비공개 사고 과정이 아니라 답변의 근거와 접근 방식을 짧게 요약한 내용이다.
- 독립적인 짧은 질문은 전체 대화를 읽지 않고 최근 문맥만 사용한다.
- `위 질문`, `그것`, `계속`, `더 자세히`처럼 이전 대화를 가리키는 표현이 있으면 필요한 대화 문맥을 유지한다.
- 긴 입력과 첨부 문서는 입력량에 맞춰 문맥 범위를 늘린다.

## 현재 요청: Mermaid 규칙과 FAST 모드

- Mermaid 다이어그램은 다크 모드에서 흰 배경을 강제하지 않는다.
- 모든 노드의 배경색과 글자색은 충분한 대비를 유지한다.
- Mermaid 라벨에 문법 충돌 가능성이 있는 특수문자가 포함되면 라벨 전체를 큰따옴표로 감싼다.
- 이 규칙을 앱에 기본 내장하고 AI 데이터센터의 `prompt_rule` 레코드로 저장한다.
- 즉시 모드 옆에 `FAST` 체크 옵션을 둔다.
- FAST는 설명 없이 답만 출력한다.
- FAST에서 Mermaid 코드를 요청하면 설명 없이 Mermaid 코드 블록 하나만 반환한다.
- FAST는 최신 사용자 입력만 사용하고 검색과 이전 대화 재독을 생략한다.
- FAST 출력 예산과 제한 시간은 설정에서 조절한다.
- 기본값은 `FAST MAX TOKEN = 3000`, `LIMIT TIME = 60초`이다.
- 상단 배치 팝업에서 AI 답변 폰트 크기를 `5~25px` 범위로 조절하고 설정을 저장한다.

## 첨부 이미지에서 확인한 실패 사례

다크 화면 안에서 `Performance Check` 결정 노드만 매우 밝은 배경으로 표시되고 글자도 밝아 대비가 무너진다. 내장 규칙은 이런 `밝은 배경 + 밝은 글자` 조합을 금지한다.
