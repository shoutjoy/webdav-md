## 3. 사용자 기능 업데이트

### 3.1 이미지 수식 인식 `img2Math`

- 수식 빠른 메뉴에 `img2Math` 버튼을 추가했다.
- 이미지 파일 선택, 드래그앤드롭, 클립보드 붙여넣기를 지원한다.
- 기존 `AIChatBridge.complete()`와 현재 선택된 비전 제공자/모델을 사용해 이미지의 수식을 LaTeX로 변환한다.
- AI 응답의 코드 펜스, JSON 래퍼, `$...$`, `$$...$$`, `\(...\)`, `\[...\]`을 정리한다.
- MathJax로 결과를 즉시 미리보기하고 사용자가 LaTeX를 수정할 수 있다.
- 팝업을 열 때 저장한 편집기 선택 위치에 블록 수식(`$$`)으로 삽입하고 자동 저장한다.
- 팝업 바깥 클릭과 `Escape`로 닫을 수 있다.

필수 연동:

- `window.AIChatBridge.complete`
- `getMermaidVisionProviderSelection()`
- `ensureMdMathEngineLoaded()` 및 MathJax
- 편집기 상태 변수와 `performAutoSave()`

### 3.2 Markdown 표 편집

- 표 삽입 그리드 아래에 `행 추가`, `열 추가`, `행 삭제`, `열 삭제` 버튼을 추가했다.
- 편집기 커서가 위치한 Markdown 표와 셀을 자동으로 탐지한다.
- 이스케이프된 파이프(`\|`)를 셀 구분자로 잘못 처리하지 않는다.
- 새 행/열을 추가할 때 표 구분선과 열 개수를 함께 맞춘다.
- 머리글 및 구분선 삭제와 마지막 한 개 열 삭제를 차단한다.
- 편집 이력, 렌더링, 목차 갱신, 자동 저장을 기존 편집 흐름과 연결했다.
- 표 삽입 그리드에 명시적인 선택 스타일과 접근성 속성을 추가했다.

### 3.3 MPV 및 ZIP 전체 백업 복원

- 백업 모달의 잘못된 `MVP 열기` 표기를 `MPV 열기`로 수정했다.
- MPV와 ZIP에 각각 전용 파일 선택 동작을 추가했으며, 같은 파일을 다시 선택해도 `change`가 발생하도록 입력값을 초기화한다.
- MPV 복원은 데이터베이스 준비를 기다린 뒤 실행하고, 잘못된 구조는 오류로 알린다.
- ZIP 내 `_mdpro_backup.json` 매니페스트를 이용해 폴더와 모든 문서를 원래 ID/연결 정보와 함께 복원한다.
- ZIP 내보내기에 다음 형식의 매니페스트가 추가된다.

```json
{
  "format": "mdpro-zip-backup",
  "version": 1,
  "exportedAt": "ISO-8601 timestamp",
  "folders": [],
  "documents": []
}
```

- 매니페스트가 없는 일반 ZIP도 `.md` 파일을 찾아 폴더와 문서로 복원한다.
- 일반 ZIP 복원 제한은 최대 2,000개 Markdown 파일, 압축 해제 문서 합계 최대 100MB다.
- `__MACOSX` 항목은 제외한다.
- 기존 문서+내부 이미지 ZIP 가져오기 경로는 유지하며, 매니페스트가 있을 때만 전체 백업 복원 경로를 우선한다.

### 3.4 Mermaid 편집기 및 inDB 미리보기

- Mermaid 이미지→코드 영역을 더 낮고 수평적인 툴바 형태로 재배치했다.
- 프롬프트 입력창의 세로 크기를 사용자가 조절할 수 있다.
- `문서 삽입` 버튼을 추가해 코드를 본문에 넣은 뒤 Mermaid 편집기를 자동으로 닫는다.
- 부모 창은 iframe 메시지의 `closeEditor: true`를 처리한다.
- `mermaid_refs` 저장소 항목의 코드 길이를 목록 보조 정보로 표시한다.
- inDB 상세 화면에서 저장된 Mermaid 코드를 `MermaidTRT.renderIn()`으로 렌더링해 미리보기한다.
- 렌더러 누락, 코드 없음, 렌더링 실패 상태를 화면에 표시한다.

### 3.5 HTML→Markdown 변환 개선

- HTML2MD와 MD2HTML을 빠른 정리 메뉴에서 나란히 배치했다.
- 체크박스가 포함된 작업 목록을 `- [ ]`, `- [x]` 형식으로 변환한다.
- 목록 항목 안의 문단과 지원하지 않는 블록 요소를 더 안정적으로 처리한다.
- 표 셀의 `align` 및 단순 `text-align` 스타일을 Markdown 정렬 구분선(`:---`, `:---:`, `---:`)으로 변환한다.
- `dl/dt/dd` 설명 목록을 굵은 용어와 설명 문단으로 변환하고 제한 보고서에 기록한다.
- `figcaption`은 강조 문장으로 변환한다.
- `address`, `aside`, `footer`, `header`, `nav` 등의 컨테이너는 내부 내용을 보존하면서 제거한다.
- Markdown으로 안전하게 표현할 수 없는 속성/태그는 원본 HTML 보존 원칙을 유지한다.

### 3.6 GitHub 설정 및 저장소 초기화 안정화

- 저장된 GitHub 활성화 상태, 토큰, 저장소, 브랜치, Pull 최대 파일 수, 기본 Push 경로를 UI 필드에 동기화한다.
- GitHub 탭 전환 시 아직 생성되지 않았거나 오래된 DOM 값 대신 저장된 설정을 우선 확인한다.
- 앱 시작 시 GitHub 설정 UI 준비와 값 동기화를 기다린다.
- 연결 성공 상태를 숨기지 않고 초록 상태 메시지로 계속 표시하며 `role=status`, `aria-live=polite`를 적용했다.
- IndexedDB 연결과 `MDPStorage` 초기화를 각각 하나의 공유 Promise로 직렬화해 중복 초기화 경쟁을 방지한다.
- 저장소 모드 전환 전에 저장소 서비스가 준비되었는지 보장한다.
- MPV 복원도 동일한 데이터베이스 준비 경로를 사용한다.

### 3.7 사이드바 폴더 및 스크롤 개선

- 검색창 옆에 모든 폴더 접기/펼치기 버튼을 추가했다.
- inDB와 GitHub 폴더 노드에 공통 `sidebar-folder-node`와 `data-folder-id`를 부여했다.
- 현재 전체 접힘 상태에 따라 화살표, 제목, `aria-label`, `aria-pressed`가 갱신된다.
- 문서 메뉴 숨김 체크박스의 텍스트를 제거하고 접근 가능한 이름은 유지했다.
- 문서 목록/목차 영역에 `min-h-0`, `overscroll-contain`을 적용해 flex 레이아웃의 내부 스크롤을 안정화했다.
- 중복된 사이드바 DOM 요소 제거 동작을 조정해 초기화 시 기존 resize handle이 있어도 셸이 설치되도록 했다.

### 3.8 편집기 이동 플로팅 컨트롤

- 편집기 좌우 이동 플로팅 컨트롤에 드래그 핸들을 추가했다.
- 세로/가로 배치 전환 버튼을 추가했다.
- 사용자가 정한 위치와 방향을 localStorage에 저장한다.
- 창 크기 변경 시 화면 밖으로 나가지 않도록 위치를 보정한다.
- 신규 키:
  - `md_viewer_editor_shift_float_position`
  - `md_viewer_editor_shift_float_orientation`

### 3.9 하이라이트 팝업 자유 이동

- 오른쪽 고정 상태에서도 하이라이트 팝업을 가로와 세로 양쪽으로 드래그할 수 있다.
- 드래그한 왼쪽 좌표와 위쪽 좌표를 레이아웃 상태에 반영한다.
- 고정 모드를 새로 켤 때 기본 왼쪽 좌표를 12px로 초기화한다.

## 6. 다른 앱에 적용하는 순서

1. 대상 앱 코드와 사용자 저장소(IndexedDB/SQLite)를 백업한다.
2. 대상 앱이 기준 커밋과 같은 계열인지 확인한다.
3. 가능하면 두 커밋을 시간순으로 cherry-pick한다.
4. 수동 이식이면 4절의 운영 코드 14개 파일을 모두 비교·병합한다.
5. 테스트도 함께 가져와 5절의 명령을 실행한다.
6. 브라우저/PWA/Electron 캐시를 비우거나 강력 새로고침한다.
7. 아래 수동 검증 체크리스트를 수행한다.

## 7. 수동 검증 체크리스트

- [ ] 앱 시작 시 inDB/SQLite 전환과 문서 목록 로딩에 오류가 없다.

- [ ] ZIP 전체 백업을 내보낸 뒤 다시 열어 폴더/문서가 복원된다.
- [ ] 기존 내부 이미지 ZIP 가져오기가 계속 동작한다.
- [ ] 수식 메뉴에서 img2Math 이미지 선택, AI 생성, 미리보기, 본문 삽입이 된다.

## 8. 호환성 및 데이터 주의사항

- 새 IndexedDB object store나 DB 버전 증가는 없다. 기존 `mermaid_refs` 저장소를 표시하는 기능만 확장했다.
- ZIP 매니페스트는 새로 추가되지만, 매니페스트 없는 일반 Markdown ZIP도 호환한다.
- img2Math는 이미지 입력을 지원하는 AI 제공자/모델과 기존 AI 설정이 필요하다.
- Mermaid inDB 미리보기는 `window.MermaidTRT.renderIn()`이 로드되어야 한다.
- ZIP 기능은 기존 로컬 `vendor/jszip/jszip.min.js` 로드에 의존한다.
- 파일 일부만 이식하면 DOM ID, 전역 함수, CSS, 캐시 키가 서로 맞지 않을 수 있으므로 기능별 부분 복사보다 전체 커밋 이식을 우선한다.

## 9. 롤백

별도 변경이 없는 동일 Git 저장소라면 오늘 커밋 두 개를 역순으로 되돌린다.

```bash
git revert a57d584f55d03c95d496d51501dd1851fa3359bf
git revert c253fb979d2f378f8dd77c86548b57cc772ce7fe
```

롤백은 새 ZIP 백업 파일 자체를 삭제하지 않지만, 이전 앱에서는 `_mdpro_backup.json`을 이용한 전체 복원 기능을 사용할 수 없다. 롤백 전 문서를 일반 `.md` 또는 기존 MPV 형식으로도 별도 보관하는 것이 안전하다.
