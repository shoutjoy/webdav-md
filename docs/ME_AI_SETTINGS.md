# WebDAV ME AI 설정

문서 ID: `WEBDAV-ME-AI-SETTINGS-01` / 2026-11-10.

Viewer의 ME_AI_SETTINGS.md 개정 1.1을 WebDAV 구조에 적용했다. [구현·대응표·검증·재명령](mdpro-development/changes/2026-11-10-me-ai-settings-port.md).

1. ENV/AI Jena에서 공급자의 주소·키를 저장한다. ME에는 키를 별도로 입력하지 않는다.
2. 이미지 → Mermaid Ref에서 AI 영역을 열고 **AI 모델**을 펼친다. 저장 선택이 없으면 AI Studio (Gemini), `gemini-3.5-flash-lite`가 기본이다. 모델은 목록 선택/직접 입력이 가능하다. 계정의 실제 사용 가능 여부는 목록 조회와 API 응답으로 확인한다.
3. **모델 새로고침**으로 연결을 확인한다. 연결됨은 모델 목록/응답 수신 성공이며 이미지 인식 품질·렌더 성공과 다르다. 공급자 목록은 WebDAV Jena와 같고 FLM은 `Lemonade FLM NPU`로 표시한다.
4. 이미지 선택·드래그·Ctrl+V·붙여넣기로 20MB 이하 이미지를 넣는다. 크게 보기의 맞춤/100%/±/Esc, 제거를 사용할 수 있다. 붙여넣기 권한이 없으면 Ctrl+V/파일 선택을 사용한다. 작은 썸네일과 원본 첨부는 분리된다.
5. **ME실행**으로 생성한다. 단계 진행률·250ms 경과 시간·토큰을 표시한다. `약`은 추정치이며 최종 usage가 있으면 갱신한다. 최종 렌더 성공 후에만 100%와 이력 저장을 표시한다. 중지는 기존 Jena 대화를 취소하지 않는다.

**AI JENA 설정 사용**은 실행 시 메인 Jena의 현재 공급자/모델을 따른다. 직접 선택하면 ME 모델은 별도 보존하고 주소·키는 메인 설정을 사용한다. Lemonade/FLM은 각 WebDAV 설정과 서버 경로를 유지하며 실패 시 다른 공급자로 우회하지 않는다. DeepSeek의 현재 이미지 분석 경로는 미지원 오류를 표시한다.

새 선택 키는 `mdv_mermaid_ai_selection_v1`이며 이전 WebDAV `mdv_ai_tool_mermaid` 선택을 자동으로 읽어 이전한다. provider/model/openAICompatibleProvider만 저장한다. opaque iframe 저장이 제한되면 저장 없이 실행을 계속한다. 부모 RPC가 키를 사용하고 자식에는 전달하지 않는다. 모델 조회 15초, 생성 부모 180초/자식 185초 제한이다.

ME의 UI/코드/미리보기 테마는 각각 분리된다. 보기 도표의 달/해 버튼은 해당 도표만 바꾸며 다른 SVG/높이/확대율과 원문 색·선을 유지한다. 전체 refresh에서 선택은 이어지지만 완전히 새 본문으로 교체한 뒤까지 개별 도표 테마를 영구 저장하지 않는다.

배포 시 부모·iframe·picker·renderer를 함께 갱신하고 먼저 새로고침/PWA 업데이트 상태를 확인한다. 사용자 데이터를 먼저 삭제하지 않는다. LM Studio 주소는 해당 장치의 실제 서버 주소와 대조한다. 원본 문서의 5678 포트·로드 모델은 그 점검 환경의 기록이며 이 앱의 고정 기본값이 아니다.

로컬 Chrome 모의 API·Node 102개·웹 빌드는 통과했다. 실제 공급자의 연결/비전 품질, 배포 사이트, Tauri·설치 앱·PV/OS 출력은 이번 작업에서 확인하지 않았다.
