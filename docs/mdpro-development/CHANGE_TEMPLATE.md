## 요청과 완료 기준

사용자에게 보이는 이전 동작과 이후 동작, 정확한 UI 문구·위치·기본값·저장 및 원본 보존 조건.

## 실제 구현

변경 파일, 함수·호출자, 처리 순서, 수정 이유, 실제 코드 발췌 또는 검토 가능한 패치. 신규 의존성과 캐시 변경도 기록.

## 상대 앱 대응표와 이식 순서

| 원본 경로·함수 | 대상 실제 경로·함수 | 확인된 차이·선행 조건 | 이식 상태 |
| --- | --- | --- | --- |
| | | | |

복사하면 안 되는 파일·앱별 초기화·브리지·저장 구조를 구체적으로 적는다. 필요한 선행 기능과 테스트 의존성을 포함한다.

## 회귀 예제와 검증

재현 입력, 예상 출력, 보존 사례, 실행 명령·종료 결과, 실제 제공 URL/캐시와 UI 증거. 원본 앱 증거를 대상 앱 증거로 대체하지 않는다. 미실행·실패·미검증은 명시한다.

## Tauri 반영 계획

대상 웹 소스 변경 파일, 빌드에 포함할 자산, 빌드 전 검사, `Tauri/dist` 확인 방법, 설치 앱 확인 항목, 빌드 대기 목록의 항목 ID. 해당 없으면 이유를 적는다.

## 다른 앱에서 다시 실행할 명령

```text
[대상 절대 경로]에서 작업해줘. AGENTS.md와 [이 기술문서의 대상 저장소 경로]를 읽고,
[정확한 기능 범위]를 대상 앱의 구조에 맞춰 구현해줘. [선행 작업]을 확인하고,
전체 파일 덮어쓰기 없이 [회귀 사례]를 검증해줘. 이식 문서·목록·Tauri 대기 상태도 갱신해줘.
[사용자 요청에 따른 빌드 포함 여부]. 미검증 항목은 구분해서 보고해줘.
```
