사용자가 API 키/질문을 https://mdproviewer.vercel.app/api/exaone을 거쳐 EXAONE으로 보내도록 명시 승인했다. WebDAV mdpro/js/app.js openAICompatibleRequestUrl은 HTTPS shoutjoy.github.io에서 공식 EXAONE chat URL만 위 relay로 매핑한다. 로컬은 Vite 중계, 사용자 URL/다른 공급자는 기존 경로 유지. mdpro/index.html app query exaonePages=20261116-1 추가. Viewer api/exaone.js는 정확한 Origin=https://shoutjoy.github.io에만 OPTIONS204, POST 및 Authorization/Content-Type/Accept를 허용한다. wildcard/쿠키/키 로그 없음. 외부·유사 출처/임의 헤더 거부, upstream 고정·SSE·취소 보존. CORS는 출처 단위이므로 같은 GitHub 사용자 도메인의 다른 경로도 동일 출처다. API key는 요청마다 기존 저장 설정에서 공급되며 서버에 저장하지 않는다.
